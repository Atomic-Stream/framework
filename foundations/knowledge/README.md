# knowledge/ — What it knows

**Question this folder answers:** what does this agent need to know about the domain, its customers, and how this Stream has settled things before?

**Maintained by:** Stream Orchestrator · **Propagation:** reviewed · **Tier:** C — blank plus worked example

Nothing here can be pre-filled: the domain, the customers, the current outcome targets, the presentation standards, and the record of how comparable questions were settled before are specific to the Stream.

The decision record is the file most likely to be skipped and the one that pays back most. It is what stops the same argument being had four times.
